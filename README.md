# Student Management System

## Project Description
A CRUD-based web application developed to manage student records efficiently.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Django
- Django REST Framework
- SQLite

## Features
- Add Student
- View Students
- Update Student
- Delete Student
- Search Student

## Student Details
- Name
- Email
- Department
- Age
- Phone

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run migrations:
   python manage.py migrate

3. Start the server:
   python manage.py runserver

4. Open in browser:
   http://127.0.0.1:8000/

## Project Type
CRUD Web Application
